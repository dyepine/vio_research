# Сохранённые результаты отчёта

Таблица: [vio_reference_table.tex](vio_reference_table.tex).
Числа до округления: [reference_results.csv](reference_results.csv).
Источники, хеши входов и предупреждения: [sources.json](sources.json).
Графики APE/RPE и траекторий: [figures/](figures/).
Стандартные результаты evo: `evaluations/<sequence>/<module>/*.zip`.
Папка занимает около 25 MB; bags, изображения датасетов и сборки сюда не входят.

## Проверка без датасетов

Из корня репозитория, обычным Python 3:

```bash
python3 scripts/build_report_table.py --check
python3 scripts/build_report_table.py  # восстановить таблицу из проверенных чисел
```

Проверяются SHA-256 сохранённых файлов, девять уникальных результатов,
совпадение RMSE между CSV, summary.json, sources.json и 36 ZIP evo,
а также протокол каждой оценки. Скрипт не вычисляет метрики заново.
`bundle.json` сопоставляет локальные файлы с исходными путями и хешами.
Исторические summaries сохранены побайтово: абсолютные пути внутри них —
описание исходной машины, для чтения bundle они не используются.

ZIP можно открыть стандартной библиотекой evo, например `evo_res`, из Pixi
окружения VSLAM-LAB. Для визуализации/сравнения нужно выбирать ZIP одной метрики.
APE ZIP содержит сопоставленные выровненные траектории; RPE ZIP — ошибки
выбранных пар. Это сохранённая оценка, а не исходные данные полного VIO replay.

## Откуда взяты числа

| Часть таблицы | Источник |
| --- | --- |
| BotanicGarden `1018_13`, GrandTour `kaeb_1` | `comparison_20261016T174628_6de5c661`, SE3-оценки от 16.10.2026 |
| GEODE `offroad1` | `comparison_20261018T182237_5927253c`, `evaluation_variants/gt_orientation_candidate/2026-10-19_10-03-08` |
| Контроль устойчивости Voxel-SVIO на GEODE | три rectified-попытки в `comparison_20261018T210952_4db73a91` |

Исходные comparison CSV лежат в `comparisons/`, конфиги запуска — в `inputs/`,
сохранённые журналы повторов — в `voxel_repeats/`. Принятая поправка ориентации
GEODE и сравнение оценок сохранены в `geode_reference/`; соглашение и его
ограничения описаны в [DATASETS.md](../../docs/DATASETS.md#geode).

Протокол таблицы: SE3 без коррекции масштаба, maxdt=0.05 s, RPE на 1 м пути GT,
relative tolerance=0.1, all_pairs=True, max_pose_gap_s=1.0. Оцениваются body-позы.
Методы имеют разные наборы timestamps; ORB-SLAM3 сохраняет ключевые кадры.
Это единичные опорные прогоны, не средние/медианы по повторам.

Матрица GrandTour/BotanicGarden изначально запускалась с `origin`; таблица
использует её последующую оценку с SE3. Поэтому `--saved-protocol` на исходном
историческом запуске сам по себе не воспроизводит эту таблицу.
Новый `configs/experiments/report.yaml` задаёт SE3 сразу.

У Voxel-SVIO метрики GEODE заменены на `×`: устойчивое прохождение не
подтверждено последующими попытками. Исходные числа опорного прогона остаются
в CSV, sources.json и ZIP, включая APE RMSE 1.503 м. Это явное правило
отображения, а не отсутствие оценки или нулевые ошибки.
Качество GT и калибровки GEODE независимо не подтверждено.

Текущие исходники содержат более позднее исправление памяти Voxel-SVIO.
Историческая таблица не выдаётся за результат текущего бинарника.
Для нового эксперимента выполните команды из [README](../../README.md)
и сравните новый результат с сохранённым; недетерминированные методы могут
давать другой результат. sqrtVINS обсуждается как дополнительная проверка
в [описании методов](../../docs/METHODS.md#sqrtvins), в эти девять строк не входит.

Авторский текст и итоговый PDF здесь не создаются и не редактируются.
