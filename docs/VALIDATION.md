## Выполненные проверки

- `make test`: 59 migration + 34 основных + 18 evaluation тестов, все 111 прошли.
- `ctest --test-dir external/VSLAM-LAB/Baselines/Voxel-SVIO/build --output-on-failure`
  с очищенным `LD_LIBRARY_PATH`: все 3 теста прошли, включая Valgrind Memcheck.
- `make run CONFIG=configs/experiments/report.yaml PLAN=1`: на подготовленных
  локальных данных материализованы 9 native recipes. Для каждой проверены stereo-vi,
  SE3 и отсутствие коррекции масштаба; три метода получают одинаковый профиль IMU
  для каждого датасета.
- `python3 scripts/build_report_table.py --check`: проверены девять результатов,
  36 ZIP evo, протоколы, хеши и совпадение таблицы с исходными числами.
- В отдельном чистом локальном recursive checkout: та же проверка прошла без
  `results/` и датасетов, из другого рабочего каталога. Удалённая таблица восстановлена
  побайтово; повреждение ZIP приводит к явной ошибке. Оба checkout остались чистыми.
- Исходные сохранённые результаты и датасеты не менялись; авторский отчёт не переписывался.

Первоначальный прямой вызов migration-тестов без `pixi` в PATH дал один сбой
`FileNotFoundError: pixi`. Штатный `make test` выставил окружение и прошёл полностью;
исправление кода для этого не потребовалось.

## Границы проверки

Полные VIO-прогоны в ходе уборки не повторялись. Native tests используют существующую
локальную сборку. Чистая установка Ubuntu, скачивание всех данных и сборка всех методов
с нуля в этой работе не выполнены. Локальный recursive checkout проверяет доставку
закоммиченных исходников и артефактов, но не доступность новых коммитов на GitHub.
Новые коммиты созданы локально в `integration/feature-history` обоих репозиториев;
для публикации сначала нужен fork, затем основной репозиторий.

GEODE остаётся предварительным метрическим сравнением из-за соглашения ориентации GT
и независимо не подтверждённой калибровки. Для Voxel-SVIO сохранены как опорные числа,
так и причины обозначения `×`. Сохранённые исходники сейчас содержат более поздний
memory fix; результаты старого бинарника не приписываются новой версии.

Для sqrtVINS подтверждены сохранённые проверки GrandTour и GEODE. Источник утверждения
об аналогичных результатах на BotanicGarden в проверенных каталогах не найден;
это остаётся пробелом в подтверждении авторского текста.

После сокращения dataset selections оставлен один `configs/datasets/selected.yaml`
с теми же тремя записями, что и в `report.yaml`. Совпадение выборов проверяет
отдельный migration-тест; для GEODE-вариантов подготовка читает experiment YAML.

## Группы коммитов

В fork отдельно оформлены GEODE, точная передача radtan5 в OKVIS1,
memory fix Voxel-SVIO с native-тестами, sqrtVINS и дополнительный SchurVINS.
В основном репозитории соответствующие конфиги и тесты закрепляют gitlink нужной
ревизии; отдельно оформлены default отчёта, сохранённые результаты и документация.
История, существовавшая до уборки, сохранена. Старые сценарии перечислены в
[EXPERIMENTS.md](EXPERIMENTS.md), прежний README — в [legacy-workflow.md](legacy-workflow.md).
