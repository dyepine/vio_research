Тесты повторно выполнены после добавления контейнерного workflow. Они включают
выбор отдельного env-файла и клонирование исходников в пустой каталог Docker volume.
Дополнительно проверены передача параметров Make, пути данных с пробелами,
перевод host-пути результата в `/results` и отказ для конфигов вне checkout.
В контейнере также прошли `make help` и проверка артефактов без датасетов.
Повторный Docker `make run PLAN=1` остановлен на первой установке окружения
ORB-SLAM3; эта попытка не подтверждает материализацию девяти recipes в контейнере.
Для изменений только текста проверяются ссылки и целостность артефактов.

## Что остаётся непроверенным

Полные VIO-прогоны при уборке не повторялись. Native tests используют существующую
локальную сборку. Образ Ubuntu собран с установкой системных зависимостей;
контейнерные Python-окружения созданы заново, без использования окружений хоста.
Полная установка Pixi без кэша, скачивание всех данных и сборка всех
методов с нуля не выполнены. Локальный checkout проверяет доставку закоммиченных
исходников и артефактов, но не доступность новых коммитов на GitHub.
Для публикации сначала должны быть доступны коммиты fork, затем основного репозитория.

Качество GNSS/INS GT и калибровки GEODE независимо не подтверждено;
принятая поправка ориентации описана в [DATASETS.md](DATASETS.md#geode).
В таблице Voxel-SVIO на GEODE имеет `×` по истории попыток, а исходные опорные
числа сохранены. Измерения исторического бинарника не приписываются текущему
исходнику с memory fix. Источники и правило отображения —
в [наборе результатов](../artifacts/report/README.md).

Для sqrtVINS подтверждены сохранённые проверки GrandTour и GEODE. Оценка
BotanicGarden в проверенных каталогах не найдена; утверждение авторского текста
о похожих результатах на этой записи пока не имеет приложенного подтверждения.
Авторский текст не редактировался, итоговый PDF и его объём не проверены.

## Исторические материалы

В рабочем наборе оставлены два эксперимента: `report.yaml` и `sqrtvins.yaml`.
Их выбор совпадает с единственным `configs/datasets/selected.yaml`.
Старые инструкции, журналы миграции и документы отдельных интеграций доступны
в Git на коммите `90ce21f`; 16 удалённых частных конфигов — на `57913a2`.
Например, для чтения прежней документации GEODE:

```bash
git show 90ce21f:docs/GEODE.md
```

Восстановление конфига не восстанавливает автоматически прежний бинарник:
ревизии, патчи и подготовку данных нужно сверять с provenance запуска.
